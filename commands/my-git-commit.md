根据当前对话上下文中涉及的修改，执行 git commit。

## 执行步骤

1. 运行 `git status` 和 `git diff`（含 `--staged`）确认变更范围。
2. 将本次相关的修改用 `git add <file>` 添加到暂存区。跳过与上下文无关的改动、敏感文件（.env、credentials 等）。
3. 若暂存区为空，直接报告"没有需要提交的修改"并结束。
4. 执行 `git commit`，提交信息按下方的格式规范撰写。

## 提交信息格式

```
<title>

<description>
```

- **title**：言简意赅，≤40 字符，中文。
- 标题后空一行，再接 description。
- **description**：详细说明改动内容，中文，Markdown 格式。代码符号、文件名不翻译。
- 不加 co-author、generated by 之类信息。
